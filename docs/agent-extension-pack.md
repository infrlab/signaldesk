# Agent extension pack

- `AGENTS.md`: durable project instructions.
- `agent-capabilities/release-review.md`: reusable QA specialist workflow and prompt.
- `agent-hooks/precommit.sh`: executable deterministic precommit gate.
- `mcp-server/README.md`: design proposal for a read-only aggregate-summary MCP tool (not deployed).
- `docs/permissions.md`: granular scope restrictions.

**Integrity note**: This is a documented extension pack with instructions, hook and reusable specialist prompt. It does not claim a running MCP server or third-party plugin. A real MCP server implementation would improve the corresponding rubric item.
